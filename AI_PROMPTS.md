# AI Prompt Trace

The following is the complete normalized prompt trace used to produce this repository. Sensitive values were not supplied.

1. "Build a functional ticketing-system MVP within two hours. Use React or Angular, a real backend and RDBMS, Redux Toolkit or equivalent, responsive design, three core unit tests, clean components, a README, setup instructions, and a complete AI prompt log. Core operations must create, view, and update tickets and include simplified authentication."
2. "Use React, Material UI, Redux Toolkit, Spring Boot, and PostgreSQL. Prioritize login, ticket CRUD and status updates. Add search/status filtering and priority management; defer WebSockets and infrastructure-heavy bonuses."
3. "Generate a Spring Boot Java 17 API with Ticket entity, validated request DTO, JPA repository, service, REST controller, centralized error responses, PostgreSQL configuration, and a simplified fixed-user login endpoint."
4. "Generate a responsive React UI with a login page, ticket cards, create/edit dialog, search and status filter. Use Redux Toolkit async thunks and Axios against the real API. Include loading, empty, confirmation, and error states."
5. "Add meaningful unit tests for create, not-found and normalized search service behavior, plus frontend filtering, label formatting and ticket validation."
6. "Review the solution for the assessment gates. Document scope rationale, stack trade-offs, skipped features, AI-generated areas, manual corrections, three-command setup, and realistic next steps."
